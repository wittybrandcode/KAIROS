# Why Uppercase by Default

All interactive labels in Kairos—buttons, tabs, panel headers, and table headers—are styled uppercase by default with wide letter-spacing.

## Why?
1. **Broadcast Hardware Heritage:** Traditional broadcast hardware uses all-caps silkscreen printing because it is highly legible in dark control rooms.
2. **Scanability:** Uppercase, widely-spaced typography creates distinct rectangular blocks of text. In high-stress, live-production environments, operators don't "read" buttons; they "scan" for shapes.
3. **Hierarchical Distinction:** By enforcing uppercase for interactive or structural elements, it sharply contrasts with sentence-case text used in paragraphs, alerts, or data rows, creating an immediate visual hierarchy.
