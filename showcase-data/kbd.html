Kbd (Keyboard Shortcuts)

Keyboard shortcuts and key labels for broadcast control surfaces.

Individual Keys (مفاتيح منفردة)

Ctrl Alt Shift Enter Esc Tab Space Del F1 F2 F5 F11

Combinations (اختصارات مركبة)

Ctrl + C Copy
Ctrl + V Paste
Ctrl + Z Undo
Ctrl + Shift + Z Redo
Alt + F4 Close Panel

Broadcast Shortcuts (اختصارات البث)

F1 Take (PGM Cut)
F2 Auto Transition
F3 Cut (DSK)
F5 Preview
F11 Fullscreen Multiview
Ctrl + T Take Selected
Ctrl + Shift + N New Rundown
